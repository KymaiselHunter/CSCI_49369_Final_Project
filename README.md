# CSCI_49369_Final_Project


## Usage

Clone the repo and navigate to project folder
```bash
  git clone git@github.com:KymaiselHunter/CSCI_49369_Final_Project.git
  cd CSCI_49369_Final_Project
  ```

Create a Virtual Environment 
```bash
  python3 -m venv venv
  ```
 
Activate the venv
macOS/Linux
```bash
  source venv/bin/activate
  ```

Windows
```bash
  venv/Scripts/activate
  ```

Install dependecies into venv from requirement.txt
```bash
  pip install -r requirements.txt
  ```
